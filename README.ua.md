## Подяки

Дякую своїм друзям та колегам на хакатоні, які запропонували ідею Двадцятого Києва та допомогли з написанням коду та зі збором даних для цього проєкту! <3

Також дякую OpenStreetMap та Leaflet за можливість використовувати їхній API для мапи, а також Вікіпедії за те, що вся інформація, що знаходиться у теці `data`, була взята з неї!

## Використання генеративного ШІ

Під час хакатону, деякі частини коду було згенеровано такими ШІ, як Claude від Anthropic, Google Gemini та ChatGPT, а саме частини, що з'єднують бекенд з фронтендом, та для виправлення деяких помилок наприкінці хакатону. Проте, усі коміти після кінця хакатону ([16 листопада 2026](## "А саме після коміту 4b22826")) не містять ніякого згенерованого ШІ коду окрім тих випадків, що будуть описані нижче у цьому розділі.
