Двадцятий Київ - інтерактивна мапа Києва впродовж XX століття (1917-1991 рр.), започаткована як проєкт на хакатон CS201.

Подяки

Дякую своїм друзям та колегам на хакатоні, які запропонували ідею Двадцятого Києва та допомогли з написанням коду та зі збором даних для цього проєкту!

Також дякую OpenStreetMap та Leaflet за можливість використовувати їхній API для мапи, а також Вікіпедії за те, що вся інформація, що знаходиться у теці "data", була взята з неї!
